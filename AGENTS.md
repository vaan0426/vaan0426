# Project instructions
## User-required backups
Before every project change, create a timestamped backup of the current affected files or a project snapshot in backups/. Verify the backup before editing. This includes HTML, CSS, scripts, images, configuration, and project instructions. Preserve original uploaded images. Avoid nesting prior ZIP archives in new archives. Backup creation itself does not require another backup. User instruction recorded 2026-10-09.

## Editorial and language requirements — 2026-10-15
Use natural Bulgarian that a Bulgarian audience can follow. Explain technical research terms. Include verified study details and meaningful limitations; never invent findings, advice, sample sizes, procedures or conclusions. Mark abstract-only access and discrepancies in the source. Preserve the distinction between association and causation, symptoms and diagnosis, and primary and exploratory outcomes. English must convey the same facts, numbers and uncertainty as Bulgarian. Maintain both languages for future articles and all public interface changes.

News illustrations must be thematically relevant and visibly varied in setting, people, framing and activity. Do not reuse a previously published news asset, its file hash or composition. Preserve older originals. Use the approved image catalogue and reject publication if no suitable unused illustration exists. Symbolic illustrations must not be represented as photographs of participants or the exact procedure studied. Do not silently introduce a paid image API.

The owner authorizes autonomous work and asks not to be interrupted for creative or routine implementation approvals. Carry authorized work through to a reviewable result. Existing sandbox and OS approval rules still apply.
