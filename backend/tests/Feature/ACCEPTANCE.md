# Интеграционни проверки преди реално използване

Тези тестове са план, не изпълнени Laravel тестове.

- Две едновременни заявки за един слот: само едната заема slot_claim; другата получава 409.
- Едновременно одобрение на две заявки с последния пакетен час: няма отрицателен баланс.
- Повторен approve и повторен Stripe webhook: няма второ приспадане или активиране.
- Reject освобождава слота; move заема новия атомарно и пази оригиналната дата.
- Потвърдена резервация се мести без втори пакетен дебит.
- Гост с изтекъл/използван токен не активира профил; зает при верификация слот връща конфликт.
- Потребител не влиза в admin host; едитор няма admin-only endpoints.
- Чужди ID на профили, заявки, поръчки и снимки не се четат/редактират.
- Замразен профил: GET разрешен; всички мутации на профил/покупки/записвания забранени.
- Вътрешни бележки липсват във всички public responses, exports и клиентски HTML.
- Изменена клиентска цена/валута/кредити се игнорира; сумите идват от сървъра.
- Снимки: content validation, size limit, executable payload rejected.
- CMS XSS е пречистен; UI е достъпен с клавиатура.
- Session fixation, CSRF, rate limiting и password reset token lifecycle.
- DST: Europe/Sofia spring gap и autumn ambiguity.
- Event capacity race и duplicate registration.
- Проверени desktop/mobile интерфейси, календар, изчерпани часове, празни/грешни форми.
