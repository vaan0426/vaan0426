# Публичен преглед през GitHub Pages

Адрес: https://vaan0426.github.io/vaan0426/

GitHub Pages публикува публичната част на сайта: начална страница, изображения, новини, архив и представяне на съдържанието. Това е статичен преглед. Административният вход, редакторът, резервациите, изпращането на формуляри и клиентските профили изискват сървър и не се представят като работещи в публичното копие.

Локалният сайт и неговият администратор продължават да работят със сървъра и SQLite базата. Не са заменени със статична версия.

## Публикуване
- Настройка на GitHub Pages: build type `workflow`.
- `.github/workflows/pages.yml` изгражда и публикува след push в main.
- `scripts/build-github-pages.cjs` създава `.pages-dist/` от разрешени публични файлове.
- `public-preview/site-data.json` е изрично ограничен публичен snapshot на CMS съдържанието и контактите. Не включва акаунти, резервации, запитвания, бележки, пароли или сесии.
- Резервните архиви, базата, backend кодът, локалните ключове и оригиналната папка „Снимки“ не се публикуват.
- Вътрешните адреси са адаптирани към `/vaan0426/`; всички оригинални проектни файлове и изображения са запазени.

При бъдещи промени само в локалната база публичният snapshot трябва също да се обнови с проверено резервно копие и да се commit/push-не. Тази статична публикация не е автоматична синхронизация на базата данни и не предоставя отдалечен Codex достъп.
